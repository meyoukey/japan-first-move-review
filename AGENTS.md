# Project Collaboration Rules

## Approval required before changes

Before editing files, changing code or configuration, or taking any other state-changing action:

1. Tell the user exactly what will change, where it will change, and why.
2. Wait for the user's explicit approval of that specific proposed change.
3. Only then perform the change.

A general instruction such as "continue" or "proceed" is not approval for a specific change that has not yet been presented.

Read-only inspection, research, and verification may be performed without approval.

## Button design

- Do not use a red primary button paired with a yellow secondary button. This does not fit Japan First Move's visual tone.
- When adding buttons, use the "Choose your card" buttons on https://japanfirstmove.com/guides/food-allergy-card-japan/ as the reference: a muted pink primary button (`#e07d99`) and a white secondary button with a pink border (`#a95b74`) and dark pink text (`#914762`).
- Keep the rounded shape and restrained hover treatment. Do not add heavy offset shadows.
- Keep the shared `.button` defaults aligned with this reference so new buttons do not bring back the rejected red/yellow pairing. Preserve established page-specific treatments unless the requested change includes them.
