# Project Collaboration Rules

## Approval required before changes

Before editing files, changing code or configuration, or taking any other state-changing action:

1. Tell the user exactly what will change, where it will change, and why.
2. Wait for the user's explicit approval of that specific proposed change.
3. Only then perform the change.

A general instruction such as "continue" or "proceed" is not approval for a specific change that has not yet been presented.

Read-only inspection, research, and verification may be performed without approval.
